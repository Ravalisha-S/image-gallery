Responsive Image Gallery

A responsive and interactive image gallery built using HTML, CSS and JavaScript.

The gallery allows users to browse images by category, view images in a larger lightbox, and navigate between images using Previous and Next controls.

Features

- Responsive image gallery layout
- Category-based image filtering
- Nature, City and Animals categories
- Image hover effects
- Interactive lightbox
- Previous and Next image navigation
- Close lightbox option
- Responsive design for different screen sizes
- Images loaded using online image sources

Technologies Used

- HTML5
- CSS3
- JavaScript

Categories

The gallery contains three image categories:

- Nature
- City
- Animals

Users can select All to display all images or choose a specific category.

How It Works

1. Open the "Image.html" file in a web browser.
2. Use the category buttons to filter images.
3. Click any image to open it in the lightbox.
4. Use Prev and Next to navigate between images.
5. Click the × button to close the lightbox.
